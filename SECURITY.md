# Security policy

Please don't report security vulnerabilities in a public issue.

Use GitHub's **Report a vulnerability** option in the repository's Security tab to send a private report to the maintainers. Include the affected version, steps to reproduce, and any relevant impact. Please don't include real secrets, credentials, or private network data in the report.

If private vulnerability reporting is not enabled for the repository, contact the maintainers privately through the contact details on their GitHub profile. Please allow time for a response before sharing the issue publicly.

Portdiag does not send telemetry or make network requests. It runs local operating-system inspection commands where available and briefly opens a TCP listener for the bind check.
